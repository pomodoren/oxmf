Andorra: a reproducible country workflow

Follow a country-scale example from reusable source data to building-level exposure and a portable dataset.

Runnable configuration · Country processing

A place, its evidence, and a repeatable method.

01

Prepare the sources

Load the country’s source data into the reusable datasource store, then copy it into the compute environment.

02

Compute and verify

Run the entity, exposure-initialization, and exposure-finalization stages, then verify the resulting buildings and assets.

03

Export and explore

Export to a portable SpatiaLite database. Prepared exposure and earthquake scenario data can be explored with the related web tools.

A clear route from inputs to outputs

OXM Mini separates reusable data preparation from computation. A country run configuration records the workflow, while logged runs retain the command, output, and final status for later review.

Keep assumptions alongside the output.

The configuration demonstrates a workflow; its presence does not establish that a fresh model run has succeeded. OXM Web’s bundled Andorra earthquake scenarios are synthetic examples, not forecasts.
