From source data to a model you can explore.

A set of tools supports the work around the OXM products: preparing data, running workflows, adapting them to places, sharing results, and turning gaps into mapping tasks.

Prepare, model, inspect, improve.

01

Prepare and model

OXM Mini runs source preparation and exposure processing. Place examples set local inputs and assumptions. The taxonomy and aggregate model supply shared definitions and calculations.

02

Inspect and share

OXM Web shows maps, profiles, and stories. Exposure Share turns database results into portable datasets.

03

Improve the evidence

Completeness tools show gaps and produce mapper exports. Document extraction is another way to bring structured evidence into review.

Different jobs, one process.

OXM MINI

Run building-level exposure

Keep reusable source preparation separate from country or area processing. Run the pinned exposure processors with Docker Compose and Make, check results, and export portable SpatiaLite datasets.

Country, area, and place-level workflows, with recorded commands and logs.

OXM EXAMPLE

Adapt the workflow to a place

Keep a study's configuration, small inputs, local occupancy and cost assumptions, and output locations together.

Processing is done by the owning OXM repositories. The example collection supplies place configurations and inputs.

EXPOSURE SHARE

Move results between workflows

Export PostGIS exposure into tiled SpatiaLite databases, merge portable datasets, and convert to Open Exposure Data format with Parquet output.

OED aggregation gives one best-estimate record per building from per-archetype records.

EXPOSURE AGENT

Extract evidence from documents

Extract structured exposure constraints from source documents through an operator-driven workflow and API.

Needs configured model and embedding services. Extracted evidence is reviewed before it is used.

Local questions shape the model.

OXM Example holds worked place configurations. They set local occupancy and cost assumptions, small inputs, and output locations, and they run through the same OXM workflows.

Turn missing attributes into fieldwork.

The place workflow links taxonomy completeness scores to mapping tasks and exports for tools such as JOSM, ODK, and QField. It moves a study from "data is missing" to a specific collection task.

Country source coverage and building-level completeness are different questions. A country can have a source input while many buildings still lack observed height, use, or construction.
